Почему меняется вес

Фиктивные оценки для проверки интерфейса. Итог и эффективные веса передаются готовыми.

Откройте страницу через локальный HTTP-сервер: python3 -m http.server 8080 --directory web, затем http://localhost:8080/dev/weights.html.

Оценку нужно объяснить

В банковском QA мало поставить балл. Нужно найти нарушение в диалоге, разобрать спор и учесть новую версию правил.

От диалога к проверяемому итогу

«Дәлел» связывает оценку с точной цитатой, проверяет её кодом и сохраняет историю решений.

Дәлел · −60HZКак работает

Ответ модели —
начало проверки

  1. Диалог

    Чат или расшифровка звонка.

  2. Модель

    Ответ по критерию + точная цитата.

  3. Код

    Сверяет цитату с оригиналом. Считает итог.

  4. Апелляция

    Человек разбирает спор. Решение в журнале.

  5. Замена критерия

    Новая версия. Пересчёт затронутых оценок.

Диалог → ответ + цитата → проверка → решение → пересчёт

Совпадение цитаты с текстом не доказывает верность вывода модели: спорные оценки проверяет человек.
